Define · POV · HMW · user story

How might we help software engineers recognize when an agent's work is drifting from the spec, before substantial work has to be redone?

Point of view

Software engineers working with agentic AI need a way to stay aware of an agent's actions and outputs as it carries out a task, because deviations from the original spec go unnoticed until substantial action or output has already been generated, increasing the time and effort required to correct them.

User story

As a software engineer working with agentic AI, I want to know when an agent's actions or outputs begin to deviate from the spec while it's working so that I can intervene before substantial work is generated in the wrong direction.

Deliver · Specline

The spec stays at the centre

  1. 01 · BeforeCheck the plan before it starts

    Spec lines with no plan step, and the agent's own choices, are flagged before any code.

  2. 02 · While it worksSee where the agent is, mid-task

    A marker beside the spec shows the line it's working on.

  3. 03 · While it worksDrift labelled on the line

    The line says what's different, and the agent keeps going.

  4. 04 · While it worksDecide right there

    Apply the fix, update the spec, or dismiss it, under the line.

  5. 05 · While it worksChange the spec while it works

    Update the spec mid-task, while the agent is still working.

  6. 06 · Before you mergeRead it all before you merge

    Every decision, spec change and code change, tied to its spec line.
